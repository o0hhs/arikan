## Kurulum

Yeni bir Ubuntu 22.04+ veya Debian 12+ sunucusunda (amd64 veya arm64):

```bash
curl -fsSL https://github.com/o0hhs/arikan/releases/latest/download/install.sh | sudo bash
```

Kurulumdan sonra yönetim menüsü için istediğiniz zaman `arikan` komutunu çalıştırın.
