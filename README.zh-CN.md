## 简介

Arikan 是 [mikan](https://github.com/Miroshka000/mikan) 的非官方分支：包含原项目的全部功能，另有推荐计划、广告活动标签、独立订阅域名、协议复制、VK TURN 等。完整说明见 [README.md](README.md)（英文）与 [README.ru.md](README.ru.md)（俄文）。

## 安装

在全新的 Ubuntu 22.04+ 或 Debian 12+ 服务器上（amd64 或 arm64）：

```bash
curl -fsSL https://github.com/o0hhs/arikan/releases/latest/download/install.sh | sudo bash
```

安装后随时运行 `arikan` 打开管理菜单。
