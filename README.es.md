## Acerca de

Arikan es un fork no oficial de [mikan](https://github.com/Miroshka000/mikan): todo lo del proyecto original más el programa de referidos, las etiquetas de campañas publicitarias, el dominio de suscripción propio, la copia de protocolos y VK TURN. Los detalles están en [README.md](README.md) (inglés) y [README.ru.md](README.ru.md) (ruso).

## Instalación

En un servidor nuevo con Ubuntu 22.04+ o Debian 12+ (amd64 o arm64):

```bash
curl -fsSL https://github.com/o0hhs/arikan/releases/latest/download/install.sh | sudo bash
```

Después de la instalación, ejecute `arikan` cuando quiera para abrir el menú de administración.
