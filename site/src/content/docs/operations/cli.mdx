---
title: Команда Arikan
description: Справочник по команде управления сервером Arikan.
---

Команда `Arikan` без аргументов открывает меню в терминале: состояние, обновления, логи, доступ, сайты REALITY, ноды, бэкапы. Те же действия доступны командами. Сами команды на английском, запускаются от root.

## Сервер

| Команда | Что делает |
|---|---|
| `arikan status` | контейнеры, процессор и память, состояние панели, доступное обновление |
| `arikan doctor` | проверить сервер панели или ноды, у каждой строки подсказка, см. ниже |
| `arikan logs [panel\|node]` | логи в реальном времени, <kbd>Ctrl</kbd>+<kbd>C</kbd> останавливает |
| `arikan restart` | перезапустить контейнеры |
| `arikan update [--check]` | обновить сейчас, сначала бэкап, при сбое откат. `--check` только проверяет |
| `arikan install [флаги]` | установка, на установленном сервере открывает меню |
| `arikan uninstall [-y]` | остановить и удалить команду, данные остаются в `/opt/mikan` |

`arikan doctor` работает на сервере панели и на сервере ноды. Проверяет Docker и контейнеры, что порты слушаются, правила ufw для порта API ноды, порта панели и портов протоколов, синхронизацию времени (`timedatectl` и заголовок Date от github.com, допуск 30 секунд), DNS, выход по HTTPS на github.com и ghcr.io (нужны для обновлений), диск (✗ меньше 500 МиБ, ! меньше 2 ГиБ) и память. На ноде ещё раз отправляет «приветствие» панели и печатает результат. Каждая строка помечена ✓, ! или ✗ и содержит подсказку; если есть ✗, команда завершается с ненулевым кодом. `arikan status` сам предложит `arikan doctor`, когда что-то не так. Это инструмент для случая, когда панель не может достучаться до ноды совсем. Тот же набор проверок для сервера панели есть в самой панели: кнопка «Проверить сервер» в **Настройки → Система**.

## Доступ

| Команда | Что делает |
|---|---|
| `arikan url` | ссылка на панель и логин |
| `arikan reset-password` | новый пароль администратора, все сессии и API-ключи отзываются |
| `arikan reset-path` | новая секретная ссылка, старая перестаёт работать |
| `arikan disable-2fa` | выключить 2FA, если потерян телефон |

## Бэкапы

| Команда | Что делает |
|---|---|
| `arikan backup` | бэкап в `/opt/mikan/backups` |
| `arikan restore FILE [-y] [--no-db-snapshot]` | восстановить из бэкапа, см. [Бэкапы](/arikan/operations/backups/) |

## Ноды и подключения

| Команда | Что делает |
|---|---|
| `arikan node list` | ноды панели |
| `arikan node add --name NAME --host IP [--domain D] [--api-port P]` | добавить ноду и получить ключ |
| `arikan node key NODE` | новый ключ ноды, старый перестаёт работать |
| `arikan node set NODE [--name] [--host] [--domain] [--enabled=true\|false]` | изменить ноду |
| `arikan join [KEY] [--panel-ip IP]` | на ноде: принять новый ключ из панели |
| `arikan inbound list` | подключения |
| `arikan inbound add PRESET [--port PORT] [--node N]` | добавить подключение, без пресета покажет список |
| `arikan inbound set NAME --port PORT [--node N]` | сменить порт, ключи и маскировка остаются |

Своя нода панели имеет номер 1, её адрес и домен меняются в настройках панели.

## Сертификаты

| Команда | Что делает |
|---|---|
| `arikan cert set --cert fullchain.pem --key privkey.pem [--node N]` | свой сертификат панели или ноды |
| `arikan cert show [--node N]` | что стоит сейчас |
| `arikan cert clear [--node N]` | вернуть автоматический сертификат (для ноды: самоподписанный) |
| `arikan cert proxy <домен>` | порт 80 держит nginx или Caddy: пропустить через него проверки центра сертификации к панели или ноде (правило с бэкапом, проверкой конфига и перезагрузкой) |

## Сайты маскировки REALITY

| Команда | Что делает |
|---|---|
| `arikan targets scan [--node N] [--json]` | найти подходящие сайты рядом с сервером |
| `arikan targets check --dest HOST:PORT [--sni NAME]` | проверить сайт |
| `arikan targets apply --dest HOST:PORT [--sni NAME] (--all \| --inbound NAME) [--force]` | поставить сайт всем подключениям или одному |

Для IP-адреса в `--dest` нужен `--sni`. Сайт проверяется перед применением, `--force` пропускает проверку.

## Адаптеры оплаты

| Команда | Что делает |
|---|---|
| `arikan addon list` | что работает и что есть в каталоге |
| `arikan addon install ID` | поставить или обновить адаптер |
| `arikan addon remove ID` | остановить и удалить, настройки и платежи в панели остаются |
